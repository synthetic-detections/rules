Microsoft 365 Administration Quick Reference
=============================================
Tenant configuration endpoints:
  admin.microsoft.com
  portal.office.com
  compliance.microsoft.com
  security.microsoft.com

Common diagnostic tools:
  DiagHost.exe - Windows built-in diagnostic data collector
  msdt.exe - Microsoft Support Diagnostic Tool

For connectivity testing, verify access to:
  login.microsoftonline.com
  outlook.office365.com
  teams.microsoft.com
