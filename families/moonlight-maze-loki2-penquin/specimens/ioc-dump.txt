Caveats
-------
- Penquin Turla's LOKI2 code reuse is the bridge connecting the 1998 era to
  the 2011-2020 Turla activity. The 2017 Securelist paper is the canonical
  reference; the attribution chain (Moonlight Maze -> Turla) is presented as
  a strong circumstantial argument, not a forensic proof.
- The cd00r-based stealth backdoor variant of Penquin does not show up in
  netstat and runs without root, so endpoint hunting must inspect process
  state via /proc rather than user-space tools.
- Sample hashes above are consensus from Leonardo + Neo23x0; ESET's
  malware-ioc Turla README does NOT contain Linux/Penquin samples (Windows
  Turla only). Cross-reference accordingly.
