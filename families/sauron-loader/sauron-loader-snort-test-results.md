## Rules

The loader beacons over HTTPS POST (Salsa20-encrypted, RSA-signed TLV body), so
the C2 payload and the Edge 143 User-Agent are inside TLS. DNS resolution and
TLS SNI of the C2 hostnames are the network tells.

| sid | Signature | Severity |
|---|---|---|
| 9001401–9001405 | DNS query for `namsb-show[.]com`, `quinlantours[.]com`, `virtual-magic[.]com`, `lahaina-shores[.]com`, `mythicinsights[.]com` (any subdomain) | high |
| 9001406–9001410 | TLS SNI to the same five domains (any subdomain) | high |

Each rule uses `content:"<domain>"; nocase; endswith;` as the fast pattern and a
dot-anchored `pcre:"/(?:^|\.)<domain>$/i"` so a look-alike registrable domain
that merely ends in the same characters (e.g. `myvirtual-magic[.]com`) does
not fire.

Result: 3/3 attack pcaps fire (7 alerts, every sid family exercised), 2/2
look-alike benign pcaps clean. `myvirtual-magic[.]com` and
`notquinlantours[.]com` satisfy the `endswith` content but are rejected by the
dot anchor, which proves the pcre guard is load-bearing.

Network rules are not corpus-FP-scanned (that applies to the YARA rules); the
look-alike benign pcaps are the FP control. The domains are disposable —
expire the rules if a domain changes owner.
