Caveats
-------
- Each infection generates a uniquely encrypted payload — hash IOCs do not survive.
- Initial access (per RHSB-2026-006) was a compromised GitHub account whose commits
  the org's CI/CD then dutifully published to npm via OIDC. The OIDC pipeline itself
  was not the root cause.
